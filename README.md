# ⚽ Projeto Copa do Mundo

Sistema Full Stack para gerenciamento de Clubes, Seleções e Jogadores.

## Tecnologias

### Backend

- ASP.NET Core (.NET 10)
- Entity Framework Core
- SQLite
- Swagger

### Frontend

- React
- TypeScript
- Vite
- Axios
- React Router

## Estrutura

ProjetoCopa
├── DotNet_React_CopaDoMundo
└── CopaDoMundo_Frontend

## Funcionalidades

- CRUD de Seleções
- CRUD de Clubes
- CRUD de Jogadores
- Relacionamentos
- Consumo da API
- Interface Web

Ver READMEs específicos do Backend e Frontend.
